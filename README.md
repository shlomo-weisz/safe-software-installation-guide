# בדיקת אימות מקומית ובטוחה

פרויקט לימודי המסביר את הסכנות בהתקנת תוכנות ממקור לא מוכר ואת תהליך האימות המומלץ לפני הרצת מתקין. הדוגמה החיה שולחת בקשה אחת בלבד לשרת המקומי ב־`127.0.0.1:9797`, ומשתמשת ביעד קבוע המכיל טקסט אזהרה לא מזיק.

## הפעלה

מתוך תיקיית `security-poc-site`:

```powershell
npm start
```

לאחר מכן פותחים בדפדפן:

```text
http://127.0.0.1:8844
```

יש לוודא ש־`yt_server.exe` מותקן ופועל. מיד בטעינת הדף נשלחת בקשת בדיקה אחת באופן אוטומטי וללא לחיצה. לאחר מכן בודקים את תיקיית Downloads. הצלחה צפויה ליצור קובץ בשם דוגמת `download-142537-483 (1).mp4`, המורכב מהשעה וממספר אקראי; תוכנו טקסט רגיל.

אם הדפדפן חוסם גישה לרשת המקומית, הבדיקה אינה מוכיחה שהשרת מאומת—רק שהדפדפן הוסיף שכבת הגנה. תוכנות מקומיות עדיין יכולות לגשת לשרת ללא אסימון.

## פריסה

האתר הוא סטטי ומוכן לפריסה ב־Vercel. קובץ האזהרה הקבוע מאוחסן ב־Google Drive ונמשך מכתובת ההורדה הישירה של אותו קובץ שיתוף. בקשת ההדגמה עצמה עדיין מוגבלת לשירות ההורדות המקומי.
